# 揽映 · Picer

Python 3.12 / PySide6 Windows x64 图片浏览器，以可扩展插件系统为核心。暗黑极简界面：单行顶栏左侧显示应用图标和「文件、编辑、视图、插件、选项、帮助」菜单，文件名居中，右侧为 5 个精致功能快捷位与窗口控制按钮。没有底栏、图片状态信息或独立工具按钮组。

0.20 画布右键新增复制图片、复制路径、在资源管理器中选中文件及切换全屏。独立「格式设置」页可选择允许读取的图片 / RAW 格式；打开、拖入、翻页和文件浏览面板共享此选择。Windows 打包程序可注册当前用户的「使用揽映打开」菜单，并注册默认图片浏览器候选后打开 Windows 默认应用页确认关联。可移除右键入口，移动程序文件夹后重新注册；设置备份不会自动执行注册。详见 [格式设置与 Windows 集成](docs/settings.md#格式设置与-windows-集成)。

0.19 系统设置移至独立的「选项」菜单，保留 Ctrl+,。设置窗口置顶且非模态，可同时操作主窗口；「应用」立即保存并生效，窗口保持打开，「保存更改」保存后关闭。「恢复默认」和「重置布局」均需确认，确认只改动表单，应用或保存后生效。选项菜单提供 JSON 导出 / 导入，备份外观、浏览、四类输入绑定、皮肤、面板布局和五个快捷位；导入先填写表单，应用后生效。详见 [设置备份与应用](docs/settings.md)。

0.18.2 修复图片画布将拖放交给内部场景而无法打开的问题：支持将本地图片拖入空白画布、已有图片和全屏画布，拖放始终复制打开，不移动源文件。外观设置使用应用自有的圆角色板，提供饱和度 / 亮度、色相、常用颜色、HEX / RGB 输入及当前 / 新颜色预览，不调用系统或 Qt 标准颜色选择器。「使用颜色」仅填入设置表单，点击「保存更改」才应用；可取消或选择「跟随皮肤」。

0.17 新增可配置的图片复制、首图 / 尾图、同级图片目录、全屏启用 / 取消、浏览面板目录操作、幻灯片播放 / 停止、浏览方向与快速访问快捷键。默认 Ctrl+C 复制图片像素（大图在后台读取原图；动态图复制当前显示帧），Backspace / Enter 操作文件浏览器，Ctrl+F 收藏浏览面板的当前目录；F11 切换全屏，启用与取消全屏没有默认快捷键。其他新增操作默认不绑定，可在「设置 → 快捷键」添加多个键盘、鼠标或触控输入并检查冲突，保留已有个人绑定。

文件浏览器搜索只按名称匹配当前层显示的文件 / 文件夹，不递归搜索；随机定位按钮选中当前层一个子目录，不进入，没有子目录时不操作。主窗口切图后，仅在浏览面板仍查看该图片所属目录时同步选中并滚动到图片；若搜索隐藏该图片，会清空搜索以便定位。浏览其他目录时不跳回。切换图片目录仅异步检查当前目录上一层的直接子目录，按名称跳过空目录、仅含更深层图片的目录及无法识别的图片，首尾提示且不循环。

「设置 → 图片浏览 → 浏览方向」可选择从左到右 / 从右到左，反向模式交换前后导航方向及双页左右位置；首图 / 尾图与绝对进度位置仍按文件名索引。「设置 → 面板与布局 → 显示所有面板的滚动条」统一控制现有、隐藏及后续加载的面板，关闭仍可滚动，开启也不会启用面板原本禁止的横向滚动条。原有动效不变。

0.16 顶部通知采用确认的纯文字、小尺寸半透明毛玻璃胶囊，鼠标 / 触控穿透，不抢焦点。功能插件启停、功能命令、全屏切换、首页 / 尾页、安装、设置保存与缓存清理显示反馈；默认停留 1 秒，通过「选项 → 系统设置 → 常规 → 操作反馈 → 通知气泡显示时长」可设 250–10000 ms。仅通知区域做小尺寸背景虚化，使用 140ms 平移进出；队列限制 5 条并去重，面板 / 缩略图动效不变。图片浏览与动态图播放两条进度栏点击直接跳至对应图片 / 帧，保留原生拖动和键盘行为，其他设置滑条操作不变。

0.15.1 使用用户提供的黄绿马赛克应用图标，透明背景保留柔和外发光；PNG 用于应用窗口 / 顶栏，七档分辨率 ICO 用于 Windows EXE。双页与触控支持自带细线图标，调用菜单、插件管理与快捷栏位统一显示；未提供图标的功能插件使用宿主默认图标，第三方自定义图标保持不变。

0.15.0 文件浏览面板采用正面毛玻璃封套，较小的文档 / 图片卡片放在内部偏右的位置。图片文件夹显示按名称排序的首张可读取图片，列表和平铺视图共用图标；预览通过宿主共享缩略图缓存异步加载，首图修改、增删和重命名后自动更新。选中描边仍包围整行 / 整个平铺项，原有动效不变。

0.14.1 修复共享缩略图缓存的磁盘写入 / 清理占用界面内存锁的问题；缓存数量索引改为增量更新，避免每秒全目录扫描。GIF / 动态 WebP 预览与播放复用同一个首帧，当前图片先预热共享内存缓存，再异步保存，减少再次解码。

0.14 四个同尺寸窗口按钮（全屏、最小化、最大化、关闭）统一跟随用户强调色。所有面板使用宿主共享缩略图缓存，存放在 `cache/thumbnails`，文件变化时自动失效；同时请求同一图片只解码一次，逐张显示已完成的缩略图。预览不限制文件总张数，通过滚轮 / 左右键浏览整个文件夹；仅加载当前可见区域和邻近图片，避免大量文件同时解码。缩略图大小仍可设置，移除旧的数量上限。自动隐藏时，原底部细长指示条与进度环共存，两者均支持悬停展开和点击固定，原有动效不变。

0.13 进度环随自动隐藏面板升降，悬停显示图片序号；**选项 → 系统设置 → 图片浏览 → 导航 → 长按方向键切换间隔** 可设置 30–2000 ms（默认 120 ms）。长按期间使用最多 960px 预览并暂停原图精修，松开后恢复；邻图预读与当前预览分开调度。信息面板的 EXIF 改为基础双列表格，底部按钮可向上展开原始、相机、照片详细信息与 GPS；RAW 相机标签独立于预览解码读取，缺失字段显示未记录。

0.12 新增微型双环进度：进度面板自动隐藏时，外环表示当前图片位置，GIF / 动态 WebP 播放时出现银灰内环表示帧进度；缩略图开启后移到预览条左侧。固定面板改为不透明炭灰，只有自动隐藏弹出的面板使用毛玻璃。**选项 → 系统设置 → 外观 → 强调色** 支持颜色选择器与 `#RRGGBB` 色值，保存后生效并在重启后保留；留空跟随皮肤，默认黄绿。原有展开、收回和缩略图动效不变。

0.11 文件浏览器新增独立快速访问与持久化历史记录、快速设置菜单和「此电脑」磁盘列表。返回上层后选中退出目录并滚动至顶部；排序按目录独立保存，普通 / 图片文件夹默认排序可在插件管理中分别配置。

0.8 默认界面采用炭灰背景、分层灰色卡片、圆角胶囊控件与黄绿强调色。强调色用于主操作、选中标记、开关与进度，面板毛玻璃保持中性灰，不被照片染成强调色。保留原有面板展开、收回、回弹与中途反向动效。

0.8.1 修复弹出菜单圆角外的矩形底色，下拉列表和各级菜单统一采用无边框圆角设计。进度条和设置滑条使用透明背景、圆形滑块与两端圆润的细轨道，横竖停靠、空列表和两端极值均保持完整。面板动效不变。

0.9.3 文件浏览器使用原创灰度毛玻璃文件夹：直接包含可解码图片时，文档卡片改为图片卡片；悬停背景略提亮，选中仅沿整行 / 整个平铺项背景描黄绿细线，图标保持灰度。上层入口置顶，所有排序方向均先显示文件夹。单击选中、双击进入目录，鼠标侧键后退 / 前进，Backspace 返回上层（编辑地址时仍删除文字）。普通滚轮每格至少滚动 180px，Ctrl＋滚轮继续调整图标。缩略预览以 280ms 渐显、轻微上移并同步压缩控制面板；220ms 平滑收回，可中途反向。原有隐藏条动效不变。

0.9.2 去除文件夹选中时展开箭头区域的原生蓝色 / 白色边缘。激活文件浏览器后，Ctrl＋滚轮以 4 像素步长调整图标，列表和平铺同步更新并保存，不改变当前目录。地址栏改为可点击的磁盘 / 文件夹层级，长名称省略显示；空间不足的中间层级收进「…」菜单。点击铅笔或在面板内按 Ctrl+L 编辑完整路径，回车跳转，Esc 取消编辑。

0.9.1 文件浏览器新增带真实图片缩略预览的列表 / 平铺切换，移除原生白色焦点框、分支框与滚动条白边。进度条拖动实时切图；缩略预览只通过弹出按钮开关，切图或自动隐藏控制面板时保持展开，控制面板收起后预览贴近底部。图片信息在窄宽度下上下排布并自动换行，避免横向溢出。

0.9 进度面板改为底部居中的紧凑悬浮条，约占窗口宽度 1/3，离底边 8px。底部只允许一个声明 `panel_role: progress` 的进度面板；其他面板只能停靠左右，并延伸到窗口底边。展开缩略图时五个按钮变矮，预览带与面板等宽，无背景底板、无滚动条，仅有图片阴影与两侧透明渐隐。缩略图大小和幻灯片间隔仍在插件管理设置中调整，数量从 0.14 起不再限制。

分发包直接安装全部示例：三个面板和负片功能默认启用，macOS 皮肤默认关闭。首次启动源码或使用新的数据目录时自动补齐随应用分发的示例。后续启动保留用户的停用、卸载、设置及自动隐藏选择；升级已安装旧示例时保留设置，并将旧进度面板位置迁移到底部。第三方 ZIP 仍需主动启用。

## 使用

从 GitHub Actions 成功运行的 **Picer-windows-x64** 产物下载 ZIP，完整解压后进入 **Picer/** 并运行 **Picer.exe**，无需安装 Python。必须保留同目录的 `_internal` 和资源文件；EXE 未签名。产物保留 30 天。

- **文件**：打开图片、打开文件夹、退出。支持将图片拖入窗口，也可传入命令行文件路径。
- **编辑**：顺时针旋转、复制当前图片、复制文件路径。旋转仅改变当前显示，不写入原图片。
- **视图**：上一张、下一张、放大、缩小、适应窗口、原始大小、全屏。
- **插件**：组件管理与设置、皮肤单选、功能启停、面板启停、功能调用及快捷栏位配置。
- **选项**：系统设置、导出设置、导入设置。
- **帮助**：关于与操作提示。
- 支持 PNG、JPEG、BMP 等 Qt 图片格式、LibRaw 相机 RAW，以及 GIF / WebP 动画播放。
- 同目录图片按文件名排序并循环切换，自动跳过损坏图片。打开失败时保留当前图片。
- 滚轮缩放，鼠标拖动平移；拖动顶栏移动窗口，双击顶栏最大化或还原，可从窗口边缘调整大小。

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+O | 打开图片 |
| Ctrl+Shift+O | 打开文件夹 |
| 左 / 右方向键 | 上一张 / 下一张 |
| Ctrl+= / Ctrl+- | 放大 / 缩小 |
| Ctrl+0 / Ctrl+1 | 适应窗口 / 原始大小 |
| Ctrl+R | 顺时针旋转 |
| Ctrl+Shift+C | 复制路径 |
| Ctrl+, | 应用设置 |
| F11 | 切换全屏（启用 / 取消可另行绑定） |
| Ctrl+C | 复制当前图片至剪贴板 |
| Backspace / Enter | 浏览面板打开父级 / 选中文件夹 |
| Ctrl+F | 浏览面板当前目录加入快速访问 |

宿主及随附插件只处理本地图片预览，不上传或修改原文件。第三方插件的行为由其代码决定。

## 插件核心

- 旋转、水平翻转与灰度预览由可启停的内置插件提供。
- 第三方插件通过版本化 SDK 扩展菜单命令、图片处理、事件、独立设置与后台任务。
- 插件管理入口：**插件 → 插件管理**，快捷键 `Ctrl+Shift+P`。
- 插件管理支持搜索、三类组件筛选和启用状态筛选；右侧「概览 / 设置」直接编辑组件选项。三个默认示例面板均不提供设置按钮。
- 软件文件夹 `examples/` 提供文件浏览器、图片信息、浏览进度面板及 macOS 皮肤；详见 [示例组件说明](docs/example-components.md)。
- 新插件默认停用；第三方 Python 插件需来自可信来源。错误记录在插件管理及日志中。
- 启动排障：`Picer.exe --safe-mode`，跳过本次第三方插件加载。

三类组件规范、快捷位与面板显示规则见 [组件开发规则](docs/components.md)。

面板统一采用无标题、无外边框的圆角外壳；固定时使用不透明炭灰，自动隐藏弹出时使用中性毛玻璃。内侧居中的三点条用于侧面板调宽，右键可自动隐藏或换边，Shift 拖动可移动已固定面板。隐藏后悬停细长边缘条展开，离开收回；点击细条靠边固定，侧面板拖动细条可在左右换边并保持隐藏；进度面板仅在底部。固定／自动隐藏仅通过三点条或指示条切换，菜单和设置页不再提供面板显示开关。位置和尺寸随配置保存。

窗口右上角依次为全屏、最小化、最大化、关闭细线按钮，均为 32px 并跟随用户设置的强调色，包括 macOS 皮肤。皮肤仅作用于宿主，不改动插件图标和内容样式。

**选项 → 系统设置** 提供常规、外观、图片浏览、面板与布局、快捷键、缓存与存储六页。可保存启动页面、窗口尺寸、宿主提示、皮肤、自定义强调色、界面密度、自动隐藏毛玻璃层次、EXIF 自动方向、循环浏览、缩放步长、双击行为和缓存容量。快捷键支持修改并检查重复；面板布局可重置。点击「应用」生效并保持窗口打开，「保存更改」生效后关闭；取消仅放弃尚未应用的编辑。面板首页、信息分类、缩略图等组件选项只在插件管理设置页调整。Windows 默认应用按钮打开系统设置；便携版仍需在系统「打开方式」中选择 Picer.exe。

完整架构、清单格式、API、生命周期与扩展边界见 [插件开发文档](docs/plugins.md)，完整示例见 [negative_plugin](examples/negative_plugin)。

## 完整软件文件夹

```text
Picer/
  Picer.exe             启动程序
  _internal/            Python / Qt 运行库
  assets/icons/         应用 SVG、PNG、ICO 图标
  plugins/              功能与面板组件
  skins/                已安装皮肤（首次安装后创建）
  cache/                缩略图与插件缓存
  config/               插件配置
  logs/                 轮转日志
  examples/             三个面板与 macOS 皮肤 ZIP；sdk/ 为回归示例
  docs/                 使用与插件开发指南
  README.txt            快速说明
  distribution.json     分发版本与架构信息
```

默认数据与软件保存在同一文件夹，移动整个目录后仍可使用。目录不可写时退回用户数据目录；通过 **帮助 → 打开应用数据目录** 查看实际位置。`--data-dir` 可指定其他数据目录，**帮助 → 清理图片缓存** 可释放宿主缩略图缓存。

更新时请解压到新目录，再迁移原 `plugins`、`skins` 与 `config`；旧单文件版的迁移步骤见 [文件夹分发指南](docs/distribution.md)。

随应用分发的示例更新会保留原组件设置和启停状态；用户卸载过的示例不会在每次启动时重新安装。需要重新安装时可使用 `examples/` 中的同名 ZIP。

## 开发与检查

安装 Python 3.12 x64，在仓库根目录执行 PowerShell：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt -e .
python -m picer
python -m ruff check .
python -m ruff format --check .
python -m pytest
```

也可以直接执行 `.\.venv\Scripts\python.exe`，无需激活虚拟环境。命令行打开图片：`python -m picer "C:\Pictures\photo.jpg"`。

Linux 无显示环境使用 `QT_QPA_PLATFORM=offscreen python -m pytest`。Linux 检查不验证 Windows EXE；请查看对应提交的 Windows Actions 实际结果。
