# 示例组件与面板交互

Picer 0.9 分发包直接安装全部示例，三个面板与负片功能默认启用，macOS 皮肤默认停用；`examples/` 同时提供 ZIP 用于重新安装。面板使用宿主统一提供的无标题、无外边框中性炭灰毛玻璃外壳。旧负片功能放在 `examples/sdk/negative-plugin.zip`，用于 SDK 与冻结打包回归验证。

| 示例 | ZIP | 默认位置 | 可配置内容 |
| --- | --- | --- | --- |
| 文件浏览器 | file-browser.zip | 左侧 | 首页目录、图标大小、列表 / 平铺视图、排序字段、升降序 |
| 图片信息 | info-panel.zip | 右侧 | 文件、尺寸、颜色、直方图、星级、其他元数据的可见性 |
| 浏览进度 | progress-panel.zip | 底部 | 缩略图大小、数量、幻灯片间隔 |
| macOS · Frost | macos-skin.zip | 宿主皮肤 | 通过皮肤菜单选择或恢复默认 |

## 设置入口

启用组件后，打开 **插件 → 插件管理 → 选择组件 → 设置**。设置表单嵌入管理页面，三个默认示例面板没有齿轮或其他设置按钮。设置由 `SettingField` 声明、宿主统一绘制，点击「保存更改」后一次保存并应用，取消不修改配置。所有设置随 `config/plugins.json` 保存。常规、外观、浏览行为等应用选项位于 **编辑 → 设置**。

当前分发包含文件浏览器 1.4、图片信息 2.2、浏览进度 1.5 和 macOS 皮肤 1.2.1。升级随附示例保留原设置、启停与自动隐藏状态，进度面板原来的侧边位置自动迁移到底部。

## 文件浏览器

使用 QFileSystemModel 按需加载真实文件系统，不递归预先扫描整盘。默认首页是系统 Pictures 图片目录；不存在时临时显示用户目录并提示修改首页。设置中可选择任意现存目录作为首页，提供首页按钮、上一级按钮和路径输入。

文件树支持多级展开，显示文件夹及常见图片格式。点击图片打开到宿主浏览器；目录可在树中展开，也可输入路径进入。列表图标大小 16～64 像素，平铺预览按两倍大小显示（32～128 像素），排序可选名称、大小、类型、修改时间，支持倒序。工具栏排序选择会直接保存。列表 / 平铺切换按钮位于工具栏右侧，也可在插件设置里选择；两种视图均异步加载真实图片缩略图。列表支持多级目录展开，列表和平铺均单击选中目录、双击进入。加载限为一个后台批次、每批最多 24 张和 256 张内存缓存，不预先解码整盘。原生白色焦点框、树分支框和滚动条边框由无边框样式替代。

文件夹采用原创灰度毛玻璃夹层图标；展开 / 收起共用同一造型。后台仅扫描可见目录的直接内容，发现可解码图片时将内部文档卡片替换为图片卡片；损坏文件不算图片，不递归扫描子目录。目录分类缓存和监听最多 256 个，单批最多 8 个；添加 / 删除图片后自动刷新。悬停使用较暗灰色背景，选中背景稍亮且整行 / 整个平铺项带黄绿细描边，包含图标和名称；图标自身没有彩色描边，展开箭头不使用原生蓝色高亮或白色边框。

上层文件夹入口始终置顶（磁盘 / 共享根目录不显示），所有排序方向均先显示文件夹。目录单击选中、双击进入；图片单击仍打开预览。鼠标侧键后退 / 前进保留最近 64 个目录历史，进入新分支时清除前进记录；Backspace 返回上层，编辑地址时只删除文字。普通滚轮每格至少 180px，触控板像素滚动加速两倍；不会在列表边界误触画布缩放。激活文件浏览面板后，按住 Ctrl 滚轮调整图标：每格 4 像素，列表 16～64 像素，平铺预览随之以两倍大小更新；尺寸保存到组件设置，当前路径、排序和视图保持不变。普通滚轮仍滚动列表。

地址栏以磁盘及文件夹层级按钮显示，点击任意一级返回该目录。长名称自动省略，悬停查看完整路径；宽度不足的中间层级收进「…」菜单，始终保留根目录及当前目录。点击铅笔或在面板内按 Ctrl+L 输入完整路径，回车跳转，Esc 取消编辑；不存在的路径保留原目录并显示提示。支持 Windows 驱动器根目录及 UNC 共享路径。

## 图片信息

后台通过 Pillow 读取原文件，画面只显示独立数据快照；快速切换图片会丢弃过期结果。显示文件名/路径/大小/修改时间、尺寸/格式/帧数/DPI、色彩模式/通道/透明度/ICC、采样平均 RGB、RGB 直方图、星级与其他可读取的文件元数据。不能读取的格式或字段显示诊断，不虚构元数据。窄面板中字段名和值改为上下排列，长路径和字段内容自动换行；分组标题、直方图和 EXIF 随宽度收缩，不产生横向滚动条。快速切图时元数据读取去抖，避免排队积压。

直方图使用对数刻度，超过 1024×1024 的图片先缩略采样，并显示实际采样尺寸。ICC、MakerNote 等二进制值展示字节数量与摘要；单个长文本截断到 2048 字符，避免巨型元数据阻塞 GUI。这是可读取元数据面板，不是 RAW 专用解码器。

星级 0～5 保存在插件配置中，不改写照片或 EXIF，最多保存最近设置的 256 张图片；读取到文件自身 Rating 时作为未自定义情况下的初值。

相机 EXIF 包含顶层标签及可读取的相机/GPS/互操作子目录。**只有文件存在 EXIF 时才显示**，不受信息分类开关隐藏。EXIF 放在根布局最底部，上方其他信息独立滚动；EXIF 区域自身可滚动且高度最多 210 像素，不覆盖其他信息。

## 浏览进度

按钮依次为上一张、下一张、弹出预览、旋转、幻灯片，采用紧凑细线图标按钮。靠边的进度条在按住拖动时实时切图，显示当前位置 `xx/xx`。空目录显示 `0/0` 并停用图片相关按钮。旋转只修改预览，幻灯片按设置间隔循环浏览。设置统一在插件管理中调整。

进度面板只在底部，宽度为窗口的约 1/3，居中并距离底边 8px。常态高 72px，缩略图展开时压缩为 52px，五个按钮从 28px 高变为 20px 高。圆头进度条始终在按钮下方。预览带与控制面板等宽，无背景底板、无滚动条，图片独立阴影，两侧渐隐；左右键或滚轮浏览，点击缩略图或回车跳转，预览保持打开；再次按弹出预览按钮才关闭。点击画布、切图或进度面板自动隐藏都不关闭预览。进度面板收起后，预览独立停靠到底部 8px 处；悬停展开或靠边固定控制面板后，预览回到控制面板上方。预览异步读取附近图片；缩略图 48～200 像素、数量 3～30、间隔 1～30 秒可在插件管理中设置，大小不会强制缩小以挤进面板。

弹出时使用 280ms OutCubic 联动动画：缩略图渐显、轻微上移 / 缩放，同时控制面板从 72px 平滑压缩到 52px，按钮从 28px 压缩到 20px。收回使用 220ms InOutCubic 反向过渡；连续点击从当前进度反向，避免闪跳。此动画独立于原有边缘悬停隐藏动效。

停用组件时停止幻灯片和动画、关闭预览并取消缩略图任务。

## macOS 皮肤边界

采用浅色窗口、圆角菜单/输入框与细线宿主功能图标。按最新窗口控件规范，右上角使用与默认皮肤一致的 32×32 黄/绿/红细线按钮。仍在 Windows 上运行，拖动、最小化、最大化和关闭使用正常 Windows 窗口行为。

宿主 QSS 会自动限定到 `picerHost` 标记的控件。面板内容、插件弹出窗、文件系统图标及插件自行提供的 QIcon 不被皮肤重绘。毛玻璃是所有面板共有的基础外壳，其颜色与插件默认内容样式独立于宿主皮肤。皮肤不修改磁盘 EXE 图标，不改变全局 QApplication 样式或操作系统设置。

## 隐藏条与悬停动效

固定面板不显示标题栏或外边框。面板内侧居中的三点拖拽条是唯一的尺寸调整入口：左/右面板调宽，进度面板保持紧凑高度。右键三点条可自动隐藏、换边；双击自动隐藏；Shift 拖动可移动固定面板。

关闭面板或进入全屏时，窗口对应边缘保留一条 **5 像素宽的细长提示条**，悬停显示面板名称。只有已启用但隐藏的面板才有提示条；停用组件完全移除它。

鼠标移入提示条时，以参考视频的形态膨胀、轻微回弹和由模糊到清晰的方式展开毛玻璃面板；移出后等待 220ms 再反向收回。展开 420ms、收回 300ms，支持中途反向过渡，避免重新从起点跳动。鼠标位于面板、提示条或使用弹出菜单/设置对话框时保持展开。

展开面板覆盖画布而不重新排列主窗口，也不修改“普通模式隐藏”偏好。窗口缩放、退出全屏、面板重新显示或停用时立即恢复正常所有权并清理浮层。展开后仍是插件的实际内容 QWidget，按钮、滚动和输入均可操作；提示条本身只保留简洁细线，不复制视频中的复杂导航栏。

**点击隐藏细条靠边固定**，即使展开动画尚未完成也可操作。**侧面板可拖动隐藏细条在窗口左右换边**，目标边缘出现黄绿高亮，松开后换边且保持自动隐藏；在其他区域松开则取消。隐藏状态、停靠边与尺寸保存，重启恢复；进度面板只允许停靠底部。全屏中固定只临时显示，退出全屏仍恢复普通模式的原隐藏选择。

毛玻璃共享一次去抖的模糊画布/图片背景缓存，加半透明蒙层与圆角，不绘制外边框；视图、缩放或图片变更后更新。它是窗口内的真实背景模糊，不依赖 Windows 桌面 DWM 效果，因此截图、测试与旧版 Windows 环境可重复验证。

0.10.0：文件浏览器的列表、平铺及缩略预览使用统一解码器，支持 RAW 预览；图片信息面板增加 RAW 源信息与可读 EXIF。
浏览进度在动态 GIF/WebP 下显示第二条可拖动的帧进度条与播放/暂停按钮，切出动画自动收回；播放条与缩略图压缩动效可同时运行，旋转不停止动画。
