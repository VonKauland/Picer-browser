# 输入与双页显示

全屏时顶栏隐藏且不占用画布空间。将鼠标停在上边缘可显示图标、菜单和窗口按钮，离开后收回；顶栏使用 180 ms 平移动画，原有面板和缩略图动画保持不变。

## 按键连击

单次按下立即切换一张图片，默认继续按住 1000 ms 后开始连击。编辑 → 设置 → 图片浏览中分别设置开始延迟（0–5000 ms）与连击间隔（30–2000 ms）。操作系统的重复按键事件不会提前触发连击。松开、失去窗口焦点、进入输入框或对话框时停止；只有连击期间启用快速预览，松开后恢复原图精修。

## 四种输入绑定

编辑 → 设置 → 快捷键。左侧选择操作，右侧使用键盘、鼠标、触控、手柄四个独立标签。包含应用操作和已启用功能插件，每个操作可保存多个绑定。

- 键盘：修改主要快捷键，或录入另一个快捷键后添加。支持修饰键和组合序列。
- 鼠标：选择单击、双击、中键、右键、前后侧键、滚轮及修饰键。只作用于图片画布；文件浏览器的原有操作不受影响。默认滚轮缩放、双击切换缩放、侧键切换图片。
- 触控：选择 L1、L2、Center、R1、R2 区域并添加；默认完全未分配。上部左右区为 L1/R1，下部为 L2/R2，中间上方 3/4 高度为 Center。只有启用触控支持时响应画布上的单指轻点，多指或移动不会触发轻点命令。
- 手柄：默认完全未分配，支持 Windows XInput 的四个设备槽。使用无品牌的非对称摇杆示意图；按手柄识别、点击示意图或从列表选择按钮，再添加绑定。支持 ABXY、方向键、肩键、扳机、摇杆按下及四向拨动、视图/菜单/引导键。选中的按钮及组合肩键使用当前强调色高亮；点击已绑定条目可查看对应位置。设备选择只影响按键识别，保存的绑定适用于全部已连接 XInput 手柄。

快捷键页使用固定外层布局：操作列表与输入页各自滚动，已绑定输入及添加/移除按钮始终保留在输入卡片下方。隐藏的手柄页不会拉长其他标签。小窗口或较大的字体下只滚动当前输入表单，键盘输入框保持紧凑。手柄使用随包分发的透明 PNG 示意图，等比例显示，按键命中位置与强调色标记共用同一缩放坐标。

### 手柄肩键组合

LB、RB、LT、RT 可以作为组合修饰键，例如 RT+A 或 LB+RT+A。在「组合肩键」勾选修饰键后选择主按钮，也可直接按住肩键再按主按钮识别。同一操作可保存多个组合。某肩键作为修饰键使用时，不可同时把它单独绑定：添加冲突绑定会询问是否覆盖，确认后移除全部冲突条目；其他肩键仍可单独绑定。按下组合只执行完整组合，不同时执行未带修饰键的主按钮操作；使用修饰键的组合未匹配时不执行主按钮的普通绑定。

手柄输入按按下边沿执行一次，按住不会重复触发；扳机和摇杆有死区及回差，避免抖动反复执行。拔插、保存绑定、进入/离开识别页后，已经按住的键不会自动触发。只有应用处于前台且没有输入框、弹出菜单或模态对话框时执行命令；识别页只选择按键，不执行图片操作。关闭插件后其绑定保留，但不会调用被卸载的命令。

XInput 是可选的系统组件，不新增依赖或第三方 DLL。Linux/不可用时仍可编辑保存绑定。引导键通过可选的扩展入口识别；部分驱动不提供该键，界面会显示可用性提示，系统自身也可能响应它。CI 验证 Windows 系统 DLL 加载和调用，并用模拟输入检查绑定与 EXE；真实手柄的识别、引导键及手感需在设备上验证。

同一个输入不能分配给不同操作。添加或保存时出现冲突，可选择覆盖原绑定或取消；键盘组合序列互为前缀也属于冲突。取消设置不会改动正在使用的绑定。旧版单个键盘快捷键自动迁移，插件关闭后不会执行其命令，重新启用会恢复其绑定。

## 预装功能插件

**显示双页**默认安装并启用插件，功能按钮初始关闭。插件 → 调用功能 → 显示双页，或分配到顶栏快捷位。两张连续图片的原始宽度均不超过当前画布宽度的一半时并排显示；上一张/下一张以一组为单位切换，例如 1/2、3/4。宽图、不可解码的第二张、最后剩余的一张均回退单页。第二张后台读取预览，停留后补全原图，与主图共用解码缓存，保留过期请求取消。图片信息和动画播放控制仍对应左侧主图，右侧动画显示首帧。

**触控支持**默认安装并启用，区域没有预设功能。其功能按钮开关仅控制是否接收触控，不会自动分配操作。快捷键设置中的触控标签用于自行配置。上述触控自动检查使用 Qt 模拟事件，真实 Windows 触屏手感仍需在设备上体验。
