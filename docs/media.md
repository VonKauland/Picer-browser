# 图片格式与浏览性能

Picer 0.13.0 的主窗口、文件浏览面板和缩略预览共用同一套格式识别与解码。
普通图片格式取决于打包的 Qt 图片插件，包括 PNG、JPEG、BMP、TIFF、WebP、GIF、SVG 等。

## 相机 RAW

使用 rawpy 0.25.1 / LibRaw 读取 CR2、CR3、NEF、NRW、ARW、RAF、ORF、RW2、DNG、PEF、SRW 等相机文件。
支持列表覆盖这些扩展名，具体相机型号、压缩方式及 RAW 变体是否可读由 LibRaw 决定；不能保证任意相机的任意 RAW 文件都能读取。
优先读取内嵌 JPEG/位图预览，不必先解包传感器数据；没有可用预览时用半尺寸解码。
停留后在后台按相机白平衡生成全尺寸 sRGB 图像，当前显示为每通道 8 位，不是 RAW 显影编辑器。
相机内嵌预览与 LibRaw 输出的色调可能有差异。信息面板显示源尺寸、传感器电平、可读取的 EXIF 与预览采样直方图；部分 RAW 格式的 EXIF 读取可能不完整。

## 动态图片

按文件内容识别 GIF 和 WebP 动画，打开后自动播放，保留逐帧延时、透明度及帧合成。
进度面板原图片进度条下方出现动画帧进度条、帧数和播放/暂停按钮。拖动后保留原来的播放/暂停状态。
切换到静态图片时自动收回播放条。播放条的淡入与面板升高共用时间轴，展开 280 ms OutCubic，收回 220 ms InOutCubic；原缩略图与边缘悬停动效不变。
缩略图展开时，按钮压缩与动画播放条仍可同时使用。旋转保留动画播放，其他插件直接替换图像会停止动画并显示替换后的静态图。
动画帧按需在后台合成，最近帧缓存最多 12 帧 / 64 MiB，不一次性加载全部帧。
GIF 从较晚位置跳回前面可能需要重新合成中间帧，大型或超长动画不能保证恒定帧率。

## 大图与大量文件

- 超过 200 万像素、2 MiB 的图片以及 RAW、GIF、WebP 在后台读取；较小普通图片保留即时打开行为。
- 普通浏览先显示最长边最多 1600 像素的预览，停留约 180 ms 后开始读取原图。两者使用同一源像素坐标，保留缩放和可见位置；原图实际到达时间由文件与磁盘决定。
- 用户快速切换时取消排队任务，忽略过期结果；原生解码调用不能在执行中强制终止。
- 向前和向后各预读一张静态图片的预览，切图复用内存缓存。解码缓存最多 24 项 / 192 MiB，按路径、修改时间、大小、预览尺寸和方向设置区分。
- 目录超过 256 项时转到后台扫描，最多保留 3 个目录索引；后续切图复用索引、位置映射与不可变路径快照，默认进度面板通过位置映射定位当前图片，并用文件系统通知更新。目录索引完成前先显示当前图片。
- 当前预览（最多 2 个工作线程）、邻图预读、原图、目录扫描分开调度，其余队列各 1 个线程，避免正在运行的邻图任务阻塞新请求。LibRaw 的 OpenMP 默认限制为最多 4 个线程，保留用户已设置的 OMP_NUM_THREADS。
- 元数据延迟读取，JPEG 使用 draft 缩小采样，磁盘缩略图写入合并并移出界面线程。

以上上限只限制相应缓存，不代表整个进程内存上限；显示图像、Qt/Pillow/LibRaw 解码临时内存另计。
单张图片限制为 1.2 亿像素，Qt 单次解码分配上限为 512 MiB，防止异常尺寸耗尽内存。
静态大图的低分辨率解码能节省多少时间取决于格式；JPEG、内嵌 RAW 预览通常受益明显，部分 PNG/TIFF 仍需读取完整源数据。

自动化测试覆盖实际生成的 DNG、GIF、动态 WebP、大图渐进替换、快速切换竞态、目录索引复用及播放条交互。
2 万项目录测试使用模拟目录项检查扫描次数和队列行为，不能视为真实磁盘测速。
Windows CI 还在实际打包 EXE 中执行 RAW 解码、动画播放、暂停、拖动以及播放条展开/收回，再验证完整目录搬迁与配置恢复。

## 长按切换与 EXIF（0.13）

在 **编辑 → 设置 → 图片浏览 → 导航** 设置长按方向键的间隔，范围 30–2000 ms，默认 120 ms。首次按下立即切换，之后由 Qt 精确定时器驱动；忽略系统自动重复事件，松开或失去窗口焦点后停止。文本编辑、选择列表、弹出菜单和设置对话框保留自身键盘操作。改过的上一张 / 下一张单组合快捷键也跟随此间隔。

长按期间优先复用已有预览，新的后台预览最长边为 960px，暂不精修原图；松开后恢复 180 ms 延迟的原图读取。沿当前方向优先预读邻图，保持缓存上限与最新请求生效的规则。已在运行的原生解码仍不能强制中断；更短间隔代表更快发出切换请求，并不保证磁盘或任意图片格式能以同等速度解码。

EXIF 基础表格包含相机制造商 / 型号、镜头制造商 / 型号、光圈、曝光时间、ISO、焦距及 35mm 等效焦距。详细信息按原始、相机、照片详细信息、GPS 分组；点底部按钮向上扩展，内部允许纵向滚动，窄面板自动换行，无横向滚动条。读取到 EXIF 时才显示，缺失字段标记未记录，不推测镜头或闪光灯厂商。

Pillow 与 ExifRead 的字段统一格式化（曝光秒数、f 值、mm、EV、GPS 度数和枚举）。RAW 标签在 LibRaw 预览 / 直方图之前独立读取，后续解码失败不清除已读标签。原始 `exif` 字典保留，新增 `exif_sections` 提供结构化表格；RAW 覆盖仍取决于 ExifRead 对具体相机文件的支持，不保证专有 MakerNote 字段完整。
