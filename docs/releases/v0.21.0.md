揽映 Picer 现提供 Windows 安装版与便携版，均包含完整应用和预装组件。

- **安装版**：下载 `Picer-0.21.0-windows-x64-setup.exe`，按向导安装。默认安装到当前用户目录，无需管理员权限。
- **便携版**：下载 `Picer-0.21.0-windows-x64-portable.zip`，完整解压后运行 `Picer/Picer.exe`。

安装时可选择创建桌面快捷方式、加入 Windows「使用揽映打开」右键菜单，以及设为默认图片浏览器。Windows 集成选项默认不勾选。

选择默认浏览器后，安装程序注册揽映并在完成页提供打开 Windows 默认应用设置的选项，由用户确认文件关联。不会改写 Windows UserChoice 或其他程序的默认关联。Windows 11 的经典右键入口可能位于「显示更多选项」。

升级保留已有配置与插件；卸载保留用户数据，只移除仍指向本安装目录的揽映注册项。便携版可以继续独立使用。

支持常见图片、相机 RAW、GIF / 动态 WebP；包含文件浏览、EXIF 信息、缩略预览、双页、插件管理与键盘 / 鼠标 / 触控 / XInput 输入绑定。

附件 `SHA256SUMS.txt` 提供安装包与便携 ZIP 的校验值。应用及安装包目前未进行数字签名。
