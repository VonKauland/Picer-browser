# 揽映 Picer 0.22.0

- 新增默认关闭的「临时编辑」面板：裁剪、拉伸、旋转、镜像、色阶、色相/饱和度/明度、指定色域保留、像素化、RGB/分通道曲线。
- 新增编辑预设下拉菜单和命名保存，在插件设置中管理与新增预设。
- 修改统一在主画布临时预览；保存时可取消、覆盖或保存 PNG 副本，完整分辨率后台生成。
- 新增默认关闭的「图片管理」面板，双列平铺、搜索排序、星级/色标筛选及数量统计，共享缩略图与标注数据。
- 图片信息面板底部固定半星评分和六色分类。
- 单侧堆叠面板新增垂直切换标签，统一应用内提示与标题栏样式。

PR 构建提供便携 ZIP、安装版及 SHA256SUMS，未合并至 main，也未发布正式 Release。
RAW 编辑结果保存为 PNG 副本；动态图暂不支持临时编辑。
