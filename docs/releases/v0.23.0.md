# 揽映 Picer 0.23.0

- **新增网络位置**：文件浏览器可添加、保存和访问网络共享。
- **新增 RAW 机内直出预览**：支持在 RAW 解码效果与文件内嵌的相机预览之间切换，便于查看机内调整后的效果；可用性与分辨率取决于原文件。
- **扩展对焦点读取**：新增尼康、索尼、富士、松下、奥林巴斯／OM System、宾得及理光 GR 等机型对应记录的解析，并完善佳能 CR3 元数据读取。照片保留有效坐标时，可在主画面显示对焦位置。
- **新增人脸与眼部区域显示**：支持多厂商的人脸记录及标准 XMP 人脸区域。标记随照片方向、旋转与缩放同步变化，具体支持取决于机型和文件记录。
- **新增 AI 生成信息读取**：识别照片内保留的 Stable Diffusion、ComfyUI 生成记录，展示模型、VAE、正负提示词、LoRA、Seed、采样参数等信息。
- **新增视频静态预览**：支持 MP4、MOV、MKV、AVI、WebM、WMV、MPEG 等主流视频格式的封面预览。
- **新增 PSD 预览**：支持查看 PSD 文件保存的合成图，主画面、文件浏览器与图片管理均可使用。
- **新增跨应用拖拽**：可从文件浏览器和图片管理面板，将原图片文件拖到其他应用程序，沿用 Windows 文件拖放方式。
- **新增插件存储管理**：在“缓存与存储”中查看插件文件占用，并可卸载独立插件。
