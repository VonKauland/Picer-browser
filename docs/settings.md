# 系统设置与备份

在 **选项 → 系统设置** 或按 **Ctrl+,** 打开设置。再次打开会激活同一个窗口，保留未应用的编辑。

设置窗口保持置顶且不阻塞主窗口。可在画布继续切图、缩放或调整面板，查看设置效果。颜色选择、输入冲突和恢复默认的确认弹窗在操作时仍需先处理。

- **应用**：立即保存并生效，设置窗口保持打开。
- **保存更改**：保存并生效，然后关闭窗口。
- **取消 / 关闭**：丢弃尚未应用的编辑；已经应用的更改仍保留。
- **恢复默认 / 重置布局**：先弹出确认，默认选择取消；确认后只重置表单，应用或保存后生效。

主窗口改变的皮肤、阅读方向和面板位置，在设置页未编辑对应项时会保留，避免应用其他选项时将它们改回。

## 导出与导入

**选项 → 导出设置** 将当前已生效的配置导出为 UTF-8 JSON；设置窗口中尚未应用的编辑不参与导出。

备份包括系统常规 / 外观 / 浏览 / 缓存选项，键盘、鼠标、触控、手柄输入绑定（包括停用功能的绑定），皮肤选择，面板位置 / 尺寸 / 固定状态及五个快捷栏位。插件自身配置、程序本体、图片、缓存和浏览历史不包含在系统设置备份中。

**选项 → 导入设置** 选择 JSON 后先校验，再填入设置窗口；当前表单中的未应用编辑会被替换。检查后点击应用或保存更改。取消窗口可放弃本次导入。导入不安装或启用功能 / 面板插件；皮肤需预先安装。未安装 / 停用功能的输入绑定和布局会保留供以后使用。

格式标记为 `picer-settings`，版本为 `1`。文件上限 8 MiB，输入绑定按操作最多 32 条、最多 512 项操作。非法范围、未知设备、重复字段、键盘前缀或手柄肩键冲突会拒绝导入，现有设置保持不变。导出采用临时文件替换，失败时保留原备份，并禁止覆盖正在使用的 `config/plugins.json`。
