# 系统设置与备份

在 **选项 → 系统设置** 或按 **Ctrl+,** 打开设置。再次打开会激活同一个窗口，保留未应用的编辑。

设置窗口保持置顶且不阻塞主窗口。可在画布继续切图、缩放或调整面板，查看设置效果。颜色选择、输入冲突和恢复默认的确认弹窗在操作时仍需先处理。

- **应用**：立即保存并生效，设置窗口保持打开。
- **保存更改**：保存并生效，然后关闭窗口。
- **取消 / 关闭**：丢弃尚未应用的编辑；已经应用的更改仍保留。
- **恢复默认 / 重置布局**：先弹出确认，默认选择取消；确认后只重置表单，应用或保存后生效。

主窗口改变的皮肤、阅读方向和面板位置，在设置页未编辑对应项时会保留，避免应用其他选项时将它们改回。

## 导出与导入

**选项 → 导出设置** 将当前已生效的配置导出为 UTF-8 JSON；设置窗口中尚未应用的编辑不参与导出。

备份包括系统常规 / 外观 / 浏览 / 缓存选项，键盘、鼠标、触控、手柄输入绑定（包括停用功能的绑定），皮肤选择，面板位置 / 尺寸 / 固定状态及五个快捷栏位。插件自身配置、程序本体、图片、缓存和浏览历史不包含在系统设置备份中。

**选项 → 导入设置** 选择 JSON 后先校验，再填入设置窗口；当前表单中的未应用编辑会被替换。检查后点击应用或保存更改。取消窗口可放弃本次导入。导入不安装或启用功能 / 面板插件；皮肤需预先安装。未安装 / 停用功能的输入绑定和布局会保留供以后使用。

格式标记为 `picer-settings`，版本为 `1`。文件上限 8 MiB，输入绑定按操作最多 32 条、最多 512 项操作。非法范围、未知设备、重复字段、键盘前缀或手柄肩键冲突会拒绝导入，现有设置保持不变。导出采用临时文件替换，失败时保留原备份，并禁止覆盖正在使用的 `config/plugins.json`。

## 格式设置与 Windows 集成

**格式设置** 单独列出常用图片和相机 RAW 格式，默认全选。应用后，打开文件、拖入图片、文件夹翻页、文件浏览面板及相邻图片文件夹导航共同遵循勾选范围；已显示的图片保留，其他图片缓存可继续复用。格式选择随 JSON 设置备份保存，导入不会自动修改 Windows 注册表。

在 Windows 运行 `Picer.exe` 时，可以使用同页的 **设为 Windows 默认图片浏览器** 按钮。程序先注册当前启用格式的「打开方式」和默认应用能力，再打开 Windows 默认应用页面，由用户确认关联；不会覆盖受保护的 `UserChoice` 或其他程序的默认关联。

**注册 Windows 右键菜单** 为已应用的格式添加「使用揽映打开」，**移除 Windows 右键菜单** 可取消此入口。Windows 11 可在「显示更多选项」中找到。注册仅写当前用户的 Picer 专属项，无需管理员权限；程序文件夹移动后应重新注册。格式修改后如需更新系统入口，应用格式后再次点击对应注册按钮。源码运行和非 Windows 系统不注册系统入口。

在画布上右键可复制图片像素、复制完整文件路径、在 Windows 资源管理器中选中图片文件及切换全屏。鼠标右键若已绑定自定义操作，保留该操作优先；键盘菜单键仍可打开画布菜单。

## 插件文件与快捷键来源

**缓存与存储 → 插件文件** 列出所有已安装插件，后台统计其独立目录的实际文件大小，包括停用插件；无法读取的目录会单独标记。随应用打包的内置代码显示「随应用提供」，不将共享运行库重复计入插件体积。

点击 **卸载** 后需再次确认。确认后立即停用并删除该插件及其配置，不需要再点应用；仍有启用的依赖插件时会提示先停用依赖者。内置代码不能单独卸载，随程序提供的独立插件包可以卸载。

**快捷键** 的操作列表在第三方插件提供的操作右侧显示插头图标。程序自带功能和预装插件不显示该标识，键盘、鼠标、触控及手柄绑定方式保持一致。
